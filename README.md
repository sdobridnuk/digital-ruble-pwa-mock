# Digital Ruble PWA Mock — v0.2

Интерактивный mobile-first mock интерфейса цифрового рубля на React + TypeScript + Vite.

## Уже реализовано

- главный экран условного банка;
- экран счета цифрового рубля с вкладками «Операции / История»;
- вертикальный сценарий «Пополнение»;
- ввод суммы и выбор банковского счета;
- отдельный экран визуальной проверки реквизитов;
- OTP-подтверждение;
- три результата: успешно / ошибка / в процессе;
- «Детально» для ошибки;
- «Обновить» для операции в процессе;
- переключатель MOCK для выбора ответа платформы;
- локальное сохранение demo-баланса;
- PWA manifest + service worker для production build.

## Рекомендуемое размещение рядом с MCP_Server

Не распаковывайте исходники прямо в корень `C:\MCP_Server`.

Рекомендуемый каталог:

```text
C:\MCP_Server\projects\digital-ruble-ui
```

Так Codex/MCP сможет работать с проектом, но файлы приложения не смешаются с `agents.json`, `server.py`, `start-ai.ps1` и служебными каталогами MCP Server.

## Что установить на Windows

Нужен только Node.js LTS. VS Code — по желанию. Ваш MCP_Server + Codex можно использовать как основную агентную среду разработки.

Проверка после установки Node.js:

```powershell
node --version
npm --version
```

## Самый простой запуск

Дважды щёлкнуть:

```text
start-demo.cmd
```

или из PowerShell:

```powershell
.\start-local.ps1
```

Скрипт сам выполнит `npm install`, если `node_modules` ещё нет, и затем запустит Vite.

Обычный ручной запуск:

```powershell
npm install
npm run dev
```

Открыть:

```text
http://localhost:5173
```

## Demo OTP

Введите любые 6 цифр или нажмите «Для demo: подставить 123456».

## MOCK режим

Кнопка `MOCK` в правом нижнем углу позволяет выбрать ответ платформы:

- Успешно;
- В процессе;
- Ошибка.

Для состояния «В процессе» после второго нажатия «Обновить» demo переводит операцию в успешное состояние.

## Production build

```powershell
npm run build
npm run preview
```

## v0.3 UI shell

Главный экран переделан в универсальное мобильное банковское приложение без названия и логотипа конкретного банка.
Добавлены обычный рублёвый счёт, накопительный счёт, валютные счета USD/EUR, быстрые действия и встроенный продукт «Цифровой рубль».
Визуальное направление: современный mobile-first banking UI с насыщенным синим акцентом, белыми карточками, крупной типографикой и мягкими скруглениями.


## v0.4
- Единая синяя нейтральная банковская тема без бренда и логотипов банка.
- Остатки на демонстрационных счетах менее 100 000 ₽.
- Текущие счета маскируются как 20-значные номера, начинающиеся с 40817810.
- Карта — 16 знаков с BIN 220015, номер маскируется.

- Добавлен 1,5-секундный spinner при обращении к банку/платформе перед результатом операции.
- Верхняя типографика крупнее; основной UI унифицирован по размеру текста.

## v0.8 — ФЛ + ИП / Альбом 2026.09
Добавлен переключатель профиля «Физлицо / ИП» и полный каталог пользовательских команд.

ФЛ: пополнение, вывод, C2C, C2B по УПК, автопереводы, C2G по УИН, C2G по свободным реквизитам, уведомления, история, PDF-документы, ограничения, согласия, управление счетом/доступом.

ИП: пополнение, вывод, B2B, B2C-возврат, B2C-выплаты по реестру, C2G по УИН, C2G по свободным реквизитам, уведомления, история, PDF-документы, ограничения, согласия, управление счетом/доступом и реквизитами ИП.

Новые сценарии построены как: ввод/получение данных → визуальный контроль → подтверждение (для денежных операций OTP) → spinner → результат.

После загрузки repository в GitHub откройте:
`Actions → Build Android APK → Run workflow`.
